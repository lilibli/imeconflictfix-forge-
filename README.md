# IME Conflict Fix

修复 Minecraft 中输入法冲突的 Forge 模组。

## 功能

- 在文本输入时**阻止空格键**触发跳跃（避免输入法确认候选词时意外跳跃）
- 在文本输入时**阻止数字键**切换快捷栏（避免输入法选词时切换物品栏）
- 在文本输入时**阻止 Tab 键**切换玩家列表
- **智能检测**输入法活动状态，仅在必要时拦截按键
- 支持中文、日文、韩文等所有非英文输入法

## 版本信息

- Minecraft: **1.21.10**
- Forge: **60.1.0**
- Java: **21**
- 模组加载器: **Forge** (非 NeoForge)

## 适用场景

| 界面 | 空格 | 数字键 | Tab | 
|------|:----:|:-----:|:---:|
| 聊天 / 命令 | ✅ 拦截 | ✅ 拦截 | ✅ 拦截 |
| 告示牌编辑 | ✅ 拦截 | ✅ 拦截 | - |
| 书与笔 | ✅ 拦截 | ✅ 拦截 | - |
| 铁砧 | ✅ 拦截 | ✅ 拦截 | - |
| 搜索框 | ✅ 拦截 | ✅ 拦截 | - |
| 普通游戏 | ❌ 放行 | ❌ 放行 | ❌ 放行 |

## 构建

```bash
./gradlew build
```
